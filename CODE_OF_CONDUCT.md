# Code of Conduct

This repository follows the Contributor Covenant Code of Conduct v2.1 (<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>).

## Expectations

- Engage with mathematical and technical critique rigorously, honestly, and respectfully.
- Separate criticism of proofs, code, or methodology from personal attacks.
- Disclose verification boundaries, computational assumptions, and potential errors transparently.
