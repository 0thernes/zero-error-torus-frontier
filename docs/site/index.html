Four Kernel-Checked Lower Bounds (C25, C29 above Codenotti–Gerace–Resta 2003; C27, C31 below)

Comparison: the largest published values we found, the d = 4 entries of Codenotti, Gerace and Resta, Ars Combinatoria 66 (2003), Table 1 (23125, 31522, 42017, 54934). The bounds for C27 and C31 are proved correctly but are weaker than the 2003 values; they are not best known. An earlier version of this page compared against older third-power values and called all four bounds world records; see ERRATA.md.

Epistemic Scope & Explicitly Open Problems

Every theorem T1a–T4d is machine-checked in standalone zero-Mathlib Lean 4.35.0 with zero sorry, zero native_decide, and strict standard axioms {propext, Classical.choice, Quot.sound} across six independent proof kernels (lean, leanchecker-paranoid, lean4lean, nanoda, con-leche, con-ron). Determining the exact value of Θ(Cn) for odd n ≥ 7 (Mega-Atlas CS-049) remains explicitly open. No published open question is resolved: Theorem T3c is a two-alphabet, two-graph form of the BPZ combining rule (Tandon, arXiv:2608.30273, Proposition 1). Shannon capacity is not defined in Lean; each capacity bound on this page follows, outside Lean, from a kernel-checked integer statement about independent sets in a strong power.
